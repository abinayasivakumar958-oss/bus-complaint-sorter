# Project Reflection (400 words)

Use this as a structure and rewrite it in your own words after completing the project. Include your actual test results and challenges. Do not submit claims about work you have not done.

## Suggested reflection structure

1. **Problem understanding:** Explain why bus complaints need to be sorted and why safety complaints should be visible to the transport officer.
2. **What you built:** Describe the two CSV inputs, LLM classification, Python validation and three output files.
3. **Technical learning:** Explain the functions, lists, dictionaries, CSV file handling, JSON, API calls and try-except blocks you used.
4. **Testing:** Report your actual five evaluation results and three red-team test results. Mention any changes you made.
5. **Limitations:** Explain that an LLM can misunderstand a complaint, that route checks reduce one type of error, and that a human must review safety issues.
6. **Future improvement:** Suggest one or two realistic improvements, such as better Tamil/Tanglish handling or a larger test dataset.

Write approximately 400 words in your own voice. Include at least one real challenge you faced and how you solved it.
